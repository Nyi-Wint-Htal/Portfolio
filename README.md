# Portfolio Website

My first portfolio website built while learning web development.

## About

This project was created to practice the fundamentals of HTML, CSS, JavaScript, and modern web development workflows. It showcases my projects, skills, and personal information.

Although this project is not fully responsive, it represents an important milestone in my learning journey and demonstrates my early understanding of web design and layout techniques.

## Features

* Personal introduction section
* Skills showcase
* Project showcase section
* Contact information
* Custom styling and layout

## Technologies Used

* HTML
* CSS
* JavaScript
* Git
* GitHub

## What I Learned

Through this project, I learned:

* Building multi-section web pages
* CSS layout fundamentals
* Styling and typography
* Organizing project files
* Using Git and GitHub for version control
